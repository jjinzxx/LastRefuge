FEATURES

SYS-01

잠입 시스템

소음과 스태미나를 관리하며 AI의 눈을 피하라. 발소리 하나가 생사를 가른다.

SYS-02

그리드 인벤토리

타르코프 스타일 10×5 그리드. 모든 아이템에는 무게가 있다. 욕심은 곧 죽음이다.

SYS-03

위협적인 AI

순찰하는 적은 시각·청각으로 탐지한다. 탐지되는 순간 모든 것이 달라진다.

SYS-04

자원 관리

희귀한 자원을 수집하고 기지에 저장하라. 다음 출격을 위한 준비가 생존이다.

// 게임플레이 루프

GAMEPLAY LOOP

01

DEPART

안전 기지에서 출발. 장비를 정비하고 루트를 설정하라.

02

INFILTRATE

폐허를 잠입 탐색. AI 순찰대의 패턴을 읽어라.

03

LOOT

컨테이너를 수색하고 자원을 획득. 무게를 계산하라.

04

RETURN

기지로 귀환. 살아 돌아오는 것이 최우선이다.

ABOUT

Last Refuge는 포스트 아포칼립스 세계관의 1인칭 하드코어 생존 게임입니다. Unreal Engine 5로 제작되었으며, 긴장감 넘치는 잠입과 자원 관리를 핵심으로 합니다.

2주 스프린트로 개발된 1인 프로젝트. 모든 시스템은 C++로 직접 구현되었습니다.
